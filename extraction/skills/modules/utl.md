`MOD-UTL` (Utilities / Access)

## Variable Conventions

Utilities and access variables capture household access to services:
electricity, water, sanitation, telecommunications, and derived expenditure
variables.

## Expected Variables

- Access to electricity
- Access to improved water source
- Access to improved sanitation
- Telecommunications access (mobile phone, internet)
- Derived utility expenditure variables

## Welfare Boundary

UTL expenditure variables (chapter 6) are **non-welfare** and included.
Chapter 8 consumption aggregates are **welfare** and excluded.
Classify each expenditure mention using the Phase 1 boundary rule.

## Common Edge Cases

- Access definitions differ by country (improved vs. unimproved sources)
- Expenditure variables may reference chapter 8 consumption — classify carefully
- Some surveys use composite access indices

## Source Patterns

The chapter typically contains:
- A summary table of utility/access variables
- Value codes for access categories
- Derivation notes for expenditure variables
