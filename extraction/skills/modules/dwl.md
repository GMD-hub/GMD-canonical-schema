## Module Code

`MOD-DWL` (Durable Welfare)

## Variable Conventions

Durable welfare variables capture household asset ownership and durable goods
indicators. These are non-welfare variables distinct from chapter 8 consumption.

## Expected Variables

- Durable goods ownership indicators
- Asset count variables
- Housing characteristics used as welfare proxies

## Welfare Boundary

DWL variables (chapter 7) are **non-welfare** and included in extraction.
Chapter 8 (CONS) variables are **welfare** and excluded.

## Common Edge Cases

- Asset ownership coding varies across surveys (binary vs. count)
- Some surveys combine durable goods with housing questions
- Asset indices may require country-specific valuation

## Source Patterns

The chapter typically contains:
- A summary table of durable welfare variables
- Asset category value codes
- Notes on housing characteristic coding
