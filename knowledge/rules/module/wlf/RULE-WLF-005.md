# Two coupled things. (1) A hard convention: skip-generated empties are KNOWN
# ZEROS, not missing — miscoding them (or a CAPI mis-skip) is a defect to fix at
# the raw data. (2) A procedure for genuine item nonresponse: diagnose the
# mechanism (determination), then act; MNAR or a material imputed share is a
# decision-log escalation. MV22 deliberately declines a universal imputation
# protocol, so this rule fixes the PROCEDURE, not a single method, and does not
# add a standing switch.

---

## Plain language rule

Before any imputation, separate two things that look identical in the data but
are not: a **known zero** and a **missing value**.

- An empty cell generated by a legitimate **skip** (the module did not apply —
  no children ⇒ no school-fee question; the household grows nothing ⇒ no
  own-production rows) is a **known zero**, not missing. Miscoding such zeros as
  missing — or a CAPI system with an incorrect skip — is a **defect to fix at
  the raw data**, not something to impute.
- A cell that is genuinely **unknown** (a lost food diary; a household that
  declined to state rent paid) is **item nonresponse** and enters the procedure
  below.

MV22 deliberately gives **no universal imputation protocol**, because the right
action depends on the variable and survey. What is standing is the *procedure*:
diagnose the missingness mechanism first, then act, then document and
sensitivity-test any imputation. Imputed values are never treated as genuine
values.

## Formal IF/THEN

```
STEP 0 — classify each empty:
  IF empty is skip-generated (universe/gate did not apply)
  THEN it is a KNOWN ZERO. Ensure it is coded 0, not missing.
       (A .c-style universe code remains legitimate where the concept is
        genuinely undefined for the row — see the missing-codes position;
        but a prompted-and-absent item is a zero, not a code.)
  IF empties are missing where a skip/zero was intended (data-processing bug or
     CAPI mis-skip)
  THEN FIX at the raw data — do not carry forward or impute.

STEP 1 — diagnose the mechanism for genuine item nonresponse (DETERMINATION):
  Build simple two-way missingness tables (by region, urban/rural, per-capita
  consumption decile, …) to assess:
    MCAR  — no systematic pattern; complete-case analysis is safe
    MAR   — missingness explained by observed auxiliaries within groups
    MNAR  — missingness depends on the unobserved value itself

STEP 2 — act on the mechanism:
  IF   MCAR (supported by the diagnostics)
  THEN complete-case is acceptable; record the determination.
  ELSE IF MAR:
       IF a modeling apparatus exists (housing → hedonic §4.5; food → demand
          systems) AND the component is material
       THEN regression-based imputation
       ELSE hot-deck (or variant) when little is known and stakes are small
  ELSE IF MNAR:
       ad-hoc modeling is required → this is a decision-log ESCALATION
       (cannot_determine); do not apply a default. Escalate per RULE-WLF-001's
       stop-and-escalate posture.

STEP 3 — for ANY imputation:
  document the missingness and the method, mark imputed values as NOT genuine,
  and run sensitivity analysis (ch. 8) on the aggregate. Never let imputed data
  shrink reported standard errors as if it were observed.
```

## Determinations produced (report, do not review)

- The classification counts: skip-zeros fixed, genuine-missing remaining.
- The diagnosed mechanism (MCAR / MAR / MNAR) and the tables supporting it.
- The imputation method applied and the imputed share per component.

## Escalation triggers (decision log → human)

- Diagnostics indicate **MNAR** for a material component.
- The imputed share is large enough that it materially moves the aggregate or
  its standard errors.
- Ambiguity between a legitimate universe-code (`.c`) and true nonresponse that
  cannot be resolved from the questionnaire skip logic.

## Prohibitions

- Do **not** treat skip-generated empties as missing, nor impute them — they are
  known zeros; fix miscoding at source.
- Do **not** drop incomplete records by default — complete-case analysis is
  biased unless MCAR is actually supported.
- Do **not** apply a single "house" imputation method blindly — the method
  follows the diagnosed mechanism and the component's materiality.
- Do **not** treat imputed values as genuine: always document and
  sensitivity-test; never report the artificially shrunken standard errors.
- Do **not** encode variable×survey "could not be harmonized" status as a column
  of constant missing codes — that belongs in the coverage manifest, not here
  (see the CLOSED missing-codes position).

## Rationale

The consumption aggregate is a sum of components (eq. 7.9); a single missing
component (rent, a lost food diary) can void the whole household total, so
missingness is load-bearing. But the most common "missingness" is not missing at
all — it is a known zero produced by a skip, and imputing it manufactures
consumption that was correctly absent. Getting the zero-vs-missing call right is
therefore the first and highest-leverage step. For genuine nonresponse, the
mechanism (not a favorite method) determines what is defensible: complete-case is
safe only under MCAR, which rarely holds; MNAR resists general rules and so must
be escalated rather than papered over with a default. Because imputation is
"seductive and dangerous," its audit — documentation plus sensitivity analysis —
is mandatory, not optional.

## Test examples

| Situation | Action |
|---|---|
| No household members in school ⇒ empty education-expenditure cells | Known zeros; ensure coded 0, not missing; no imputation |
| Data-processing routine replaced zeros with missing | Defect — fix at raw data |
| Rent-paid blank for some owner households, pattern varies by urban/rural | Genuine nonresponse; diagnose (likely MAR); regression/hedonic impute; document + sensitivity |
| Better-off households disproportionately refuse to report expenditure | MNAR signal — escalate; do not apply a default imputation |
| A whole food diary lost for a household | Item nonresponse at component scale; diagnose + treat per procedure; observation-level `.b` where truly unusable |
| Missingness shows no pattern across region/decile | MCAR supported; complete-case acceptable; record it |
